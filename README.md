# Northside Barbers (demo)

Demo website for a fictional barber shop in Manchester, UK. Dark editorial style with big outlined numbers, curtain image reveals, service filters, animated counters, open now badge and a booking form that writes the WhatsApp message.

Live: https://mohammadgulab.github.io/demo-barber/

Design and code by Mohammad Gulab. Photos from Wikimedia Commons, credited in the page footer.
